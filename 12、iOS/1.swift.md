# TypeScript vs Swift 详细对比指南
参考：https://doc.swiftgg.team/documentation/the-swift-programming-language/thebasics/

> 为前端工程师准备的学习对照表

---

## 1. 基础类型

### 原始类型

| 场景 | TypeScript | Swift | 注意 |
|------|-----------|-------|------|
| 整数 | `number` | `Int`, `Int32`, `Int64` | Swift 需指定位数，TS 统一用 `number` |
| 浮点 | `number` | `Double`, `Float` | TS `number` 包含两者 |
| 字符串 | `string` | `String` | Swift 更强大，支持多行字符串 |
| 布尔 | `boolean` | `Bool` | Swift `Bool` 不接受任何隐式真假值转换 |
| 空值 | `null`, `undefined` | `nil` | Swift 统一用 `nil`，TS 有两种 |

### 代码示例

```typescript
// TypeScript
let num: number = 42;
let str: string = "hello";
let flag: boolean = true;
let nothing: null = null;
let perhaps: undefined = undefined;
```

```swift
// Swift
var num: Int = 42
var str: String = "hello"
var flag: Bool = true
var nothing: Nil = nil  // 几乎不这样用
var perhaps: Void        // 不用 undefined 的概念
```

**关键差异：** Swift 要求 `:` 后面指定类型，TS 则是可选的。

### 元组（Tuple）

| 维度 | TypeScript 元组 | Swift 元组 |
|------|----------------|-----------|
| 本质 | 就是 JS 数组（运行时无元组类型） | 独立的复合**值类型**（类似轻量 struct） |
| 声明 | `[string, number]` | `(String, Int)` |
| 索引访问 | `t[0]`、`t[1]`（方括号） | `t.0`、`t.1`（点语法） |
| 命名元素 | `[name: string, age: number]`，标签仅文档用，**仍按下标访问** | `(name: String, age: Int)`，标签是**真正的访问器**：`t.name` |
| 值/引用语义 | 引用（数组对象） | 值类型，赋值/传参是**拷贝** |
| 长度 | 可被 `push` 等破坏（运行时不安全） | 固定，无法增删 |
| 数组方法 | 有（`map`/`length` 等，因为是数组） | 无，不是集合 |
| 相等比较 | 无内置 `==`，需手动比较 | 元素都 `Equatable` 时可直接 `==`（最多 6 元） |
| 高级特性 | 支持可选元素 `?`、剩余元素 `...`、展开 | 不支持可选/剩余/展开 |
| 解构 | `const [a, b] = t` | `let (a, b) = t` |

```typescript
// TypeScript
let t: [name: string, age: number] = ["Alice", 25];
t[0];              // "Alice"，标签不能用于访问
const [n, a] = t;  // 解构
t.push("oops");    // 运行时允许，类型不安全
t.map(x => x);     // 有数组方法
```

```swift
// Swift
let t: (name: String, age: Int) = ("Alice", 25)
t.0          // "Alice"
t.name       // "Alice"，命名标签是真访问器
let (n, a) = t   // 解构
// t.push(...)   ❌ 没有这种操作，长度固定
let t2 = t       // 值拷贝
print(t == ("Alice", 25))  // ✅ 可直接比较

// 最典型用途：函数多返回值
func minMax(_ arr: [Int]) -> (min: Int, max: Int) {
    return (arr.min()!, arr.max()!)
}
let r = minMax([3, 1, 2])
r.min   // 1
```

**一句话总结：** TS 元组是"贴了类型标签的数组"，本质仍是引用类型且可被破坏；Swift 元组是真正的固定长度值类型，命名标签可直接访问，常用于函数多返回值。

## 2. 变量和常量声明

| 特性 | TypeScript | Swift |
|------|-----------|-------|
| 变量 | `let`/`const`/`var` | `var` |
| 常量 | `const` | `let` |
| 类型推断 | 支持 | 支持 |

### 代码对比

```typescript
// TypeScript
const name = "Alice";      // 类型推断 string
let age = 25;              // 类型推断 number
var count = 0;             // 已过时，避免使用

// 显式类型
const user: {name: string, age: number} = {name: "Bob", age: 30};
```

```swift
// Swift
let name = "Alice"          // 类型推断 String
var age = 25               // 类型推断 Int
// Swift 没有 var 作用域问题

// 显式类型
let user: (name: String, age: Int) = (name: "Bob", age: 30)
// 或用 struct（推荐）

// 延迟初始化
var count: Int
count = 10
```

**关键差异：**
- TS 用 `const` 表示常量，Swift 用 `let`
- TS 用 `let` 表示块作用域变量，Swift 用 `var`
- Swift 没有 `undefined`，一切都必须初始化

## 3. 函数定义

### 基本函数

```typescript
// TypeScript
function greet(name: string): string {
  return `Hello, ${name}`;
}

// 箭头函数
const add = (a: number, b: number): number => a + b;

// 可选参数
function sayHi(name?: string): void {
  console.log(name || "Guest");
}

// 默认参数
function multiply(x: number, y: number = 2): number {
  return x * y;
}
```

```swift
// Swift
func greet(name: String) -> String {
  return "Hello, \(name)"
}

// 闭包（类似箭头函数）
let add: (Int, Int) -> Int = { a, b in a + b }
// 或简写
let add = { (a: Int, b: Int) -> Int in a + b }

// 可选参数
func sayHi(name: String?) {
  print(name ?? "Guest")
}

// 默认参数
func multiply(_ x: Int, _ y: Int = 2) -> Int {
  return x * y
}
```

**关键差异：**
- Swift 函数名后跟参数列表，返回值用 `->`
- Swift 参数有"参数标签"（parameter label），默认第一个参数要带标签
- Swift 用 `_` 省略参数标签：`multiply(3, 4)` vs `multiply(x: 3, y: 4)`
- Swift 没有 `undefined`，用 `Optional` 表示可选

### 参数标签（Swift 独特）

```swift
// 参数标签 vs 参数名
func move(from start: Int, to end: Int) {
  // start 和 end 是"参数标签"
  // 调用时必须写标签
}

move(from: 0, to: 10)  // ✓ 正确
move(0, 10)            // ✗ 错误

// 用 _ 省略标签
func move(_ start: Int, _ end: Int) {
  // 调用时不需要标签
}

move(0, 10)  // ✓ 正确
```

### 可变参数（Variadic Parameters）

```typescript
// TypeScript
function sum(...nums: number[]): number {
  return nums.reduce((a, b) => a + b, 0);
}

sum(1, 2, 3);  // 6
```

```swift
// Swift
func sum(_ nums: Int...) -> Int {
  return nums.reduce(0, +)
}

sum(1, 2, 3)  // 6
```

## 4. 可选类型（最重要的差异！）

这是 Swift 最独特的特性之一。

### 一个引子：为什么转换会返回可选？

```swift
let possibleNumber = "123"
let convertedNumber = Int(possibleNumber)
// convertedNumber 的类型是 Int?（可选 Int），不是 Int
```

因为字符串转数字**可能失败**，Swift 无法保证运行时一定成功：

```swift
Int("123")    // 成功 → Optional(123)
Int("abc")    // 失败 → nil
Int("12.5")   // 失败 → nil（不是整数）
```

所以返回类型只能是"要么有值、要么没值"的 `Int?`，**强制你在使用前处理"没值"的情况**。

### 可选类型的本质与作用

核心目的：**把"可能为空"写进类型系统，逼你在编译期处理空值，从根上消灭空指针崩溃。**

`Int?` 本质是个枚举，只有两种状态：

```swift
enum Optional<Wrapped> {
    case none           // 即 nil
    case some(Wrapped)  // 包裹着真实值
}
```

因此**不能直接拿 `Int?` 当 `Int` 用**，必须先"解包"：

```swift
let convertedNumber = Int("123")   // Int?

// ❌ 直接用报错：可选值不能直接参与运算
// let x = convertedNumber + 1

// ✅ 方式1：可选绑定 if let
if let number = convertedNumber {
    print(number + 1)   // number 是已解包的 Int
} else {
    print("转换失败")
}

// ✅ 方式2：空合并运算符，给默认值
let safe = convertedNumber ?? 0    // 失败就用 0

// ✅ 方式3：guard let（提前退出）
guard let number = convertedNumber else { return }

// ⚠️ 方式4：强制解包（确定有值才用，nil 会崩溃）
let forced = convertedNumber!
```

### TypeScript 中的可选

```typescript
// 三种表示可能为空的方式
let name: string | null = null;
let age: string | undefined = undefined;
let value: string | null | undefined = null;

// 可选链操作符
const len = name?.length;  // name 可能为 null

// 无效合并操作符
const displayName = name ?? "Guest";
```

### Swift 中的可选

```swift
// 声明可选类型
var name: String? = nil
var age: Optional<String> = nil  // 等价语法

// 强制解包（如果确定有值）
let len = name!.count  // 如果 name 是 nil，崩溃！

// 可选链（安全）
let len = name?.count  // 返回 Int?，如果 name 是 nil 则返回 nil

// 无效合并操作符
let displayName = name ?? "Guest"

// if-let 绑定（解包推荐）
if let unwrappedName = name {
  print(unwrappedName.count)
}

// guard-let（提前退出）
func processName(_ name: String?) {
  guard let name = name else {
    print("No name provided")
    return
  }
  print(name.count)
}
```

对照 TS，会发现**运算符层面几乎一一对应**（因为 TS 的 `?.`/`??`/`!` 本就借鉴自 Swift），只有 `if-let`/`guard-let` 是 Swift 独有的"判空+解包绑定"语法，TS 只能用类型收窄近似：

```typescript
let name: string | null = null;

// 强制解包 → 非空断言（完全对应）
const len1 = name!.length;        // Swift: name!.count

// 可选链 → 可选链（完全对应）
const len2 = name?.length;        // Swift: name?.count

// 空合并 → 空合并（完全对应）
const displayName = name ?? "Guest";   // Swift: name ?? "Guest"

// if-let → 类型收窄（仅相似：无专门绑定语法，收窄后变量作用域不受限）
if (name != null) {
  console.log(name.length);
}

// guard-let → 提前 return（仅相似：靠收窄，无 guard 关键字）
function processName(name: string | null) {
  if (name == null) {
    console.log("No name provided");
    return;
  }
  console.log(name.length);   // 收窄为 string
}
```

| Swift | TS | 对应程度 |
|-------|----|---------|
| `name!.count` | `name!.length` | ✅ 完全一致 |
| `name?.count` | `name?.length` | ✅ 完全一致 |
| `name ?? "Guest"` | `name ?? "Guest"` | ✅ 完全一致 |
| `if let x = name {}` | `if (name != null) {}` | ⚠️ 仅相似（无绑定、作用域不受限） |
| `guard let x = name else {}` | `if (name == null) return` | ⚠️ 仅相似（无 guard 语法） |

### `if let` 解包详解（标准方式）

`if let` 之所以是解包的标准方式，是因为它**在判空的同时把值安全地解出来**，且解出的变量**只在大括号作用域内有效**，编译期就杜绝了误用。

```swift
let possibleNumber = "123"

// 基本用法：转换成功才进入分支，number 是已解包的 Int
if let number = Int(possibleNumber) {
    print(number + 1)   // 124，这里 number 是 Int，不是 Int?
} else {
    print("转换失败")
}
// print(number)  // ❌ 报错：number 只在 if 大括号内可见

// Swift 5.7+ 简写：变量同名时可省略右边
let name: String? = "Alice"
if let name {           // 等价于 if let name = name
    print(name.count)
}

// 多重绑定：任意一个为 nil 都不进入分支
if let a = Int("1"), let b = Int("2") {
    print(a + b)        // 3
}

// 带条件：解包后还能加判断
if let age = Int("20"), age >= 18 {
    print("成年：\(age)")
}
```

对比"先判空再用"的笨办法，`if let` 一步到位且更安全：

```swift
// ❌ 啰嗦且不安全（仍是可选，还得强制解包）
let opt = Int("123")
if opt != nil {
    print(opt! + 1)     // 还得用 ! 解包
}

// ✅ if let：判空 + 解包合一，作用域内是非可选类型
if let n = Int("123") {
    print(n + 1)
}
```

对应到 TS，最接近的是**类型收窄（narrowing）**，但 TS 收窄后变量作用域不像 Swift 那样被严格限制：

```typescript
const n = toInt("123");      // number | undefined
if (n !== undefined) {
  console.log(n + 1);        // 收窄为 number
}
// 这里 n 仍然可见（作用域不受 if 限制）
```

### TS 与 Swift 可选能力对照

| Swift | TypeScript |
|-------|-----------|
| `Int?` | `number \| undefined`（或 `number \| null`） |
| `nil` | `undefined` / `null` |
| `if let x = opt {}` | `if (x !== undefined) {}`（类型收窄 narrowing） |
| `opt ?? 0` | `opt ?? 0`（**空合并运算符，TS 直接借鉴了 Swift**） |
| `opt?.foo` | `opt?.foo`（**可选链，也是同源思想**） |
| `opt!`（强制解包） | `opt!`（非空断言，跳过检查） |

```typescript
// TypeScript 对应写法
function toInt(s: string): number | undefined {
  const n = Number(s);
  return Number.isInteger(n) ? n : undefined;
}

const converted = toInt("123");   // number | undefined
const safe = converted ?? 0;      // 空合并，和 Swift 一样
if (converted !== undefined) {
  console.log(converted + 1);     // 类型收窄后可安全使用
}
```

**关键差异：**
- TS 用 `| null | undefined`，Swift 用 `?` 表示 `Optional<T>`
- TS 的 `?.` 和 Swift 的 `?.` 类似
- Swift 的 `if-let` 是解包的标准方式
- **Swift 是强制**：`Int?` 和 `Int` 是两个不同类型，编译器不允许不解包就使用，安全性是硬约束
- **TS 是半强制**：开启 `strictNullChecks` 后类型层面会提示，但运行时 JS 不存在可选类型，可用 `!`/`any` 绕过，约束更松

**一句话总结：** 可选类型就是把"这里可能没东西"变成编译器看得见、必须处理的类型。Swift 做得彻底（专门的 `Optional` 类型 + 强制解包），TS 用联合类型 + `strictNullChecks` 模拟，思路一致但没那么硬。

### 对象/Struct

```typescript
// TypeScript - 定义类型
interface User {
  name: string;

}

// 创建对象
const user: User = {
  name: "Alice",
```

```swift
// Swift - 定义结构体
struct User {

// 创建对象
let user = User(name: "Alice", age: 25)  // 自动生成初始化器

print(user.name)
```

```typescript
// TypeScript
let numbers: number[] = [1, 2, 3];
let items: Array<string> = ["a", "b"];

numbers.push(4);
numbers.map(x => x * 2);
numbers.filter(x => x > 2);
```

```swift
// Swift
var numbers: [Int] = [1, 2, 3]
let items: Array<String> = ["a", "b"]

// 方法（几乎一样！）
numbers.append(4)
numbers.map { $0 * 2 }

// $0 是闭包的默认参数名
```

```typescript
// TypeScript
const dict: Record<string, number> = {
```

```swift
let dict: [String: Int] = [

var mutableDict: [String: Int] = [:]
```

## 6. 类和结构体

这是两种语言的重大差异！

| 特性 | TypeScript | Swift |
|------|-----------|-------|
| 类 | 引用类型 | 引用类型 |
| 结构体 | 不存在 | 值类型（更常用） |
| 继承 | 支持 | 仅类支持 |
| 初始化器 | constructor | init |

### 结构体（Swift 推荐）

```typescript
// TypeScript - 用 interface + 工厂函数
interface Point {
  x: number;
  y: number;
  distance(): number;
}

function createPoint(x: number, y: number): Point {
  return {
    x,
    y,
    distance() {
      return Math.sqrt(x * x + y * y);
    }
  };
}
```

```swift
// Swift - 用 struct
struct Point {
  var x: Double
  var y: Double
  
  func distance() -> Double {
    return sqrt(x * x + y * y)
  }
}

let p = Point(x: 3, y: 4)  // 自动生成初始化器
```

### 类（面向对象）

```typescript
// TypeScript
class Animal {
  name: string;
  
  constructor(name: string) {
    this.name = name;
  }
  
  speak() {
    console.log(`${this.name} makes a sound`);
  }
}

class Dog extends Animal {
  speak() {
    console.log(`${this.name} barks`);
  }
}
```

```swift
// Swift
class Animal {
  let name: String
  
  init(name: String) {
    self.name = name
  }
  
  func speak() {
    print("\(name) makes a sound")
  }
}

class Dog: Animal {
  override func speak() {
    print("\(name) barks")
  }
}
```

**关键差异：**
- Swift 推荐用 `struct`（值类型，更安全，无引用问题）
- Swift `class` 必须显式 `override`，TS 没有
- Swift 结构体自动生成初始化器，避免样板代码

## 7. 属性观察器（Swift 特有）

TypeScript 没有直接对应物。

```swift
class Temperature {
  var celsius: Double {
    didSet {
      print("Temperature changed to \(celsius)")
    }
    willSet {
      print("Temperature will change to \(newValue)")
    }
  }
  
  // 计算属性
  var fahrenheit: Double {
    get {
      return celsius * 9/5 + 32
    }
    set {
      celsius = (newValue - 32) * 5/9
    }
  }
  
  init(celsius: Double) {
    self.celsius = celsius
  }
}

var temp = Temperature(celsius: 20)
temp.celsius = 25  // 触发 willSet 和 didSet
```

TS 接近的方式是用 getter/setter：

```typescript
class Temperature {
  private _celsius: number;
  
  get celsius(): number {
    return this._celsius;
  }
  
  set celsius(value: number) {
    console.log(`Temperature will change to ${value}`);
    this._celsius = value;
    console.log(`Temperature changed to ${value}`);
  }
  
  constructor(celsius: number) {
    this._celsius = celsius;
  }
  
  get fahrenheit(): number {
    return this.celsius * 9/5 + 32;
  }
  
  set fahrenheit(value: number) {
    this.celsius = (value - 32) * 5/9;
  }
}
```

## 8. 枚举（Enum）

Swift 的枚举比 TS 强大得多。

### 基本枚举

```typescript
// TypeScript
enum Color {
  Red,
  Green,
  Blue
}

let c: Color = Color.Red;

// 字符串枚举
enum Direction {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT"
}
```

```swift
// Swift
enum Color {
  case red
  case green
  case blue
}

let c: Color = .red  // 类型明确时可以省略类型名

// 字符串枚举
enum Direction: String {
  case up = "UP"
  case down = "DOWN"
  case left = "LEFT"
  case right = "RIGHT"
}

print(Direction.up.rawValue)  // "UP"
```

### 关联值（Swift 独特！）

```swift
// Swift - 枚举可以关联值
enum Result {
  case success(data: String)
  case failure(error: String)
  case pending
}

let result: Result = .success(data: "Hello")

// 模式匹配提取值
switch result {
case .success(let data):
  print("Success: \(data)")
case .failure(let error):
  print("Error: \(error)")
case .pending:
  print("Pending...")
}
```

TS 没有直接对应，通常用 Tagged Union：

```typescript
type Result = 
  | { type: "success"; data: string }
  | { type: "failure"; error: string }
  | { type: "pending" };

const result: Result = { type: "success", data: "Hello" };

switch (result.type) {
  case "success":
    console.log("Success:", result.data);
    break;
  case "failure":
    console.log("Error:", result.error);
    break;
  case "pending":
    console.log("Pending...");
}
```

## 9. 协议和接口

```typescript
// TypeScript - Interface
interface Drawable {
  draw(): void;
}

interface Resizable {
  resize(width: number): void;
}

// 实现多个接口
class Shape implements Drawable, Resizable {
  draw() {
    console.log("Drawing...");
  }
  
  resize(width: number) {
    console.log(`Resizing to ${width}`);
  }
}
```

```swift
// Swift - Protocol
protocol Drawable {
  func draw()
}

protocol Resizable {
  func resize(width: Int)
}

// 遵循多个协议
struct Shape: Drawable, Resizable {
  func draw() {
    print("Drawing...")
  }
  
  func resize(width: Int) {
    print("Resizing to \(width)")
  }
}

// Protocol 可以有默认实现（extension）
extension Resizable {
  func resize(width: Int) {
    print("Default resize to \(width)")
  }
}
```

**关键差异：**
- Swift Protocol 可以提供默认实现（通过 extension）
- Swift Protocol 支持关联类型（Associated Types）
- TS Interface 是编译时构造，Swift Protocol 可用于运行时

## 11. 错误处理

### TypeScript - Promise/Try-Catch

```typescript
// 回调错误
try {
  const result = JSON.parse(jsonStr);
} catch (error) {
  console.error(error);
}

// Promise
function fetchUser(id: number): Promise<User> {
  return fetch(`/users/${id}`)
    .then(res => res.json())
    .catch(error => {
      throw new Error(`Failed to fetch: ${error}`);
    });
}

// Async/Await
async function getUser(id: number): Promise<User> {
  try {
    const res = await fetch(`/users/${id}`);
    return res.json();
  } catch (error) {
    throw new Error(`Failed to fetch: ${error}`);
  }
}
```

### Swift - Error Protocol

```swift
// 定义错误类型
enum NetworkError: Error {
  case badURL
  case requestFailed(reason: String)
  case decodingFailed
}

// 函数抛出错误
func fetchUser(id: Int) throws -> User {
  guard let url = URL(string: "https://api.example.com/users/\(id)") else {
    throw NetworkError.badURL
  }
  
  let (data, response) = try URLSession.shared.data(from: url)
  
  guard let httpResponse = response as? HTTPURLResponse,
        (200...299).contains(httpResponse.statusCode) else {
    throw NetworkError.requestFailed(reason: "Invalid response")
  }
  
  let decoder = JSONDecoder()
  return try decoder.decode(User.self, from: data)
}

// 调用处理错误
do {
  let user = try fetchUser(id: 1)
  print(user)
} catch NetworkError.badURL {
  print("Invalid URL")
} catch NetworkError.requestFailed(let reason) {
  print("Request failed: \(reason)")
} catch {
  print("Unknown error: \(error)")
}
```

**关键差异：**
- TS 用 Promise 和 async/await，Swift 用 throws 和 do-catch
- TS 异常是值（任何东西可以 throw），Swift 必须遵循 Error protocol
- Swift 在编译时检查是否处理错误（try 关键字强制）

## 14. 集合操作

两种语言都支持函数式编程风格。

```typescript
// TypeScript
const numbers = [1, 2, 3, 4, 5];
```

```swift
// Swift - 几乎一样！
let numbers = [1, 2, 3, 4, 5]
```

## 19. 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| `Type 'String?' has no member 'count'` | 解包可选值 | 用 if-let 或 `?.count` |
| `Value of type 'Int' has no member 'description'` | 需要用 `String()` 转换 | `String(x)` 或 `"\(x)"` |
| Cannot assign to constant | let 是常量 | 改用 `var` |
| `No exact matches in call to initializer` | 缺少参数标签 | 检查函数签名 |
| `Argument passed to call that takes 2 positional arguments, but 3 were given` | 参数个数错误 | 检查参数个数 |

```swift
enum MathError: Error {

  }
```
